# Ground layer textures

`public/assets/ground/layers/` is baked by `scripts/bake-ground-layers.mjs` from
1K diffuse maps. All sources are CC0 (public domain, no attribution required).

| Layer | Source | Licence |
|-------|--------|---------|
| `grass` | [ambientCG Grass004](https://ambientcg.com/view?id=Grass004) | CC0 |
| `mossy` | [ambientCG Ground037](https://ambientcg.com/view?id=Ground037) | CC0 |
| `litter` | [Poly Haven dry_decay_leaves](https://polyhaven.com/a/dry_decay_leaves) | CC0 |
| `cracked` | [Poly Haven dry_ground_01](https://polyhaven.com/a/dry_ground_01) | CC0 |
| `grit` | The project's existing `ground/path/ground_0109` dirt | As that texture |

Do not add assets from sites that redistribute paid packs, or textures whose
licence forbids redistribution: these files ship in the repository.
